# 🕊️ DOVE AI Workstation

游戏场景智能分析工具 - 一款专为游戏场景从业者打造的专业级画质诊断工具。

## 🌟 功能特点

### 双轨制 AI 驱动
- 使用文本/多模态大模型进行深度解析
- 使用图像模型进行推演重绘

### 本地混合计算
- 利用 HTML5 Canvas 在本地提取灰阶直方图、色彩情绪光谱、几何透视骨架
- 完全纯前端运行，无需后端服务器

### 安全隐私
- 通过用户自己的 API Key 直连 Google 官方接口
- 数据不经过任何第三方服务器

## 🚀 如何使用

1. 访问工具的在线体验地址
2. 在左侧边栏填入你自己的 `Google Gemini API Key`
   *(如果您没有 Key，可以在 [Google AI Studio](https://aistudio.google.com/app/apikey) 免费申请)*
3. 点击「加载云端模型」，分别选择推理模型与生图模型
4. 拖入或粘贴您的图片，开始体验！

## 🛠️ 技术栈

- **Frontend:** HTML5, Vanilla JavaScript, Tailwind CSS
- **API:** Google Gemini API (`generativelanguage.googleapis.com`)
- **Markdown Rendering:** Marked.js
