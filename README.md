# 🧪 Freddie's AI Workstation

欢迎来到我的 AI 实验室！这里存放着我利用 AI 技术开发的一系列纯前端 Web 应用工具。
所有的工具都**无需后端服务器**，直接在浏览器中利用本地算力与强大的云端大语言模型（LLMs）进行交互。

## 🌟 当前收录工具

### 1. 🎮 游戏场景分析 Pro (Game Scene Analyzer)
一款专为游戏原画师、美术总监和 3A 游戏爱好者打造的专业级画质诊断工具。
* **双轨制 AI 驱动**：使用文本/多模态大模型进行深度解析，使用图像模型进行推演重绘。
* **本地混合计算**：利用 HTML5 Canvas 在本地提取灰阶直方图、色彩情绪光谱、几何透视骨架。
* **安全隐私**：完全纯前端运行，通过用户自己的 API Key 直连 Google 官方接口，数据不经过任何第三方服务器。

## 🚀 如何使用
1. 访问工具的在线体验地址。
2. 在左侧边栏填入你自己的 `Google Gemini API Key`。
   *(如果您没有 Key，可以在 [Google AI Studio](https://aistudio.google.com/app/apikey) 免费申请)*
3. 点击“加载云端模型”，分别选择您想使用的**推理模型**与**生图模型**。
4. 拖入或粘贴您的图片，开始体验！

## 🛠 技术栈
* **Frontend:** HTML5, Vanilla JavaScript, Tailwind CSS
* **API:** Google Gemini API (`generativelanguage.googleapis.com`)
* **Markdown Rendering:** Marked.js
